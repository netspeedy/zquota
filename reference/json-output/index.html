Reference/JSON output

JSON output

Every field in zquota's --json and --jsonl output, with its type and where it comes from, and what --raw prints.

--json prints one object for the whole run, and --jsonl prints one object per window. Both use the same values; --jsonl has fewer fields with shorter names. Numbers from Z.ai are converted to floating-point, so 62 becomes 62.0, and any value zquota doesn’t have is null.

—json

Section titled “—json”

Top level

Section titled “Top level”
FieldTypeMeaning
planstringThe plan’s level from Z.ai’s data.level, or unknown if it had none.
quotasarrayOne object per window, in the order Z.ai listed them.
fetched_atstringWhen zquota wrote the output, in UTC, as ISO 8601 with a +00:00 offset and microseconds.

fetched_at ends in +00:00, while resets_at_utc ends in Z. Both are valid ISO 8601 and parse the same way.

Each window

Section titled “Each window”
FieldTypeFromMeaning
namestringtype, unit, numberThe long name, such as 5-Hour Rolling Token Quota. See Quota windows.
name_compactstringtype, unit, numberThe short name: 5h-rolling, weekly, tool/search or unknown.
typestring or nulltypeZ.ai’s window type, as sent.
percentage_usednumber or nullpercentageThe share of the window used, as sent.
percentage_remainingnumber or nullpercentage100 minus percentage_used, kept between 0 and 100.
usage_limitnumber or nullusageThe window’s limit.
current_valuenumber or nullcurrentValueHow much of it you’ve used.
remaining_unitsnumber or nullremainingHow much is left.
resets_instring or nullnextResetTimeCountdown to the reset, such as 2h 13m 5s, or now. See Reset times.
resets_atstring or nullnextResetTimeThe reset in the chosen timezone, as YYYY-MM-DD HH:MM:SS ZONE.
resets_at_utcstring or nullnextResetTimeThe reset in UTC, as ISO 8601 ending in Z.
reset_epoch_msinteger or nullnextResetTimeThe reset in milliseconds since 1970 UTC, as Z.ai sent it.
timezonestringthe timezone settingThe timezone resets_at is in, such as Europe/London.
detailsarrayusageDetailsPer-model usage as objects with model and usage, or empty.

model and usage in details are Z.ai’s modelCode and usage, as sent, with unknown in place of either if it’s missing.

—jsonl

Section titled “—jsonl”
FieldSame as in --json
planplan
quotaname_compact
pct_usedpercentage_used
pct_remainingpercentage_remaining
remainingremaining_units
resets_inresets_in
resets_atresets_at
resets_at_utcresets_at_utc

JSON Lines leaves out the long name, type, the limit and used figures, timezone, details and fetched_at. If Z.ai returns no windows at all, --jsonl prints one empty line.

—raw

Section titled “—raw”

--raw prints Z.ai’s answer pretty-printed with two-space indentation, exactly as it was parsed, once zquota knows it’s a JSON object. Nothing is renamed, converted or checked, so the fields are Z.ai’s own, such as nextResetTime in milliseconds and percentage as Z.ai sends it. The fields zquota reads from it are listed in Quota windows.

Stability

Section titled “Stability”

zquota keeps the field names and meanings above stable for scripts. When one has to change, the change is deliberate and this page says so.
