## Usage

```bash
zquota [-j | --jsonl | -c | --raw] [--no-color] [-z TIMEZONE]
       [--api-key API_KEY] [--api-url API_URL] [-w SECONDS] [-t PERCENT]
zquota --version
```

zquota takes no arguments other than flags. With none it prints the default view once and exits.
A flag's value can follow it after a space or an equals sign, `--watch 30` or `--watch=30`, and a
short form can take its value straight after it, as in `-w30`. Long flags can be shortened to any
unambiguous prefix, such as `--thresh 80`, though scripts are clearer with the full name.

## API key and endpoint

<FlagTable flags={connection} />

Z.ai's endpoint is `https://api.z.ai/api/monitor/usage/quota/limit`. zquota sends it one `GET` per
run, or one per refresh with `--watch`, with the key as a bearer token.

[Environment variables](/zquota/reference/environment/) covers the variables these flags override.

## Watch and threshold

<FlagTable flags={running} />

zquota checks these values before it reads the API key or makes a request. `--watch` below 1,
`--threshold` outside 0 to 100, or `--threshold` with `--raw` each stop it with an error and exit
code 1. A value that isn't a number, such as `--watch soon`, is a usage error with exit code 2.

## Information

<FlagTable flags={info} />

`--version` prints a line such as `zquota 0.1.3`, the version without a `v`. Both exit with code 0
without reading the API key.

An unknown flag, two output formats at once or a value of the wrong type prints the usage line and
the problem to standard error and exits with code 2. [Exit codes](/zquota/reference/exit-codes/)
has the rest.
